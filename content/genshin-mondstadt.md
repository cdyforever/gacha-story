## 故事从何处开始 {id:intro, spoiler:light}

旅行者与血亲在离开提瓦特时被未知神明拦下。血亲被带走，旅行者沉睡多年；再次醒来时，身边只剩下被从水里钓起来的派蒙。两人决定寻访七神、寻找血亲，第一站是风神护佑的自由城邦蒙德。

但序章很快把「找亲人」的个人旅程，与另一个寻求答案的生命并置起来：东风之龙特瓦林曾守护蒙德，如今却以「风魔龙」之名袭击城市。它究竟背叛了故乡，还是被故乡先一步遗忘？旅行者要寻找失散的血亲，温迪则要唤回失散的朋友。两条「重逢」的线，从低语森林第一次见面时就已经叠在一起。

::: insight 阅读这篇故事，可以抓住三个问题
**守护是否一定意味着服从？** 特瓦林记得「四风守护」的职责，却不知道没有神明的命令之后，自己为何还要守护蒙德。

**理解是否一定来自多数人的声音？** 城市只看见灾厄，温迪却先听见痛苦。琴后来选择私下帮助旅行者，也是在公开立场与真实判断之间寻找缝隙。

**拯救是否等于替别人安排正确答案？** 温迪最终没有替特瓦林卸下责任，也没有命令它继续承担。他把选择留给了特瓦林——这正是整章最重要的答案。
:::

## 三幕完整走读 {id:acts}

### 第一幕 捕风的异乡人 {act, ver:序章·Ⅰ, p:[2,15], spoiler:light, sub:林间初遇 → 龙灾袭城 → 四风守护庙宇 · P2-P15}

旅行者在星落湖的七天神像前第一次接触风元素，随后与派蒙朝蒙德城前进。低语森林里，他们看见一个陌生少年正对巨龙低声说话。少年没有武器，也没有下令，只是安抚它：「不用怕。放心啦，我回来了。」旅行者的到来惊动了巨龙，少年与龙先后离去，原地只留下一枚流动着赤红光芒的泪滴结晶。

这一幕先给出了故事的答案，却暂时没有给出人物的姓名。读者后来会知道，少年是温迪，巨龙是特瓦林；但在初遇时，重要的不是身份，而是两者相处的方式：面对所有人畏惧的庞然大物，少年说的第一句话不是「停下」，而是「我回来了」。特瓦林的痛苦首先被当作一个朋友的痛苦，而不是一场等待清除的灾害。

::: scene 林间初遇：在「风魔龙」之前，先有人叫它特瓦林
> …不用怕。
> …放心啦，我回来了。
> —— 神秘少年 · 魔神任务「林间相会」

这两句话把整章的关系定下来了。温迪不是第一次面对特瓦林的失控，也不是来审判它；他是回到一段被毒血、沉睡与误解中断的旧关系里。后来他说自己在林中本想为特瓦林清除诅咒，却因旅行者等人的到来被打断，说明这次相遇并非偶然寒暄，而是一次未能完成的救助。

那枚赤色结晶则是另一个伏笔。派蒙只能判断它「很危险」，旅行者却能在之后将它净化。巨龙无法言说的痛苦，先以物质形式留了下来；旅行者净化污秽的能力，也因此成为温迪愿意求助的实际原因。
:::

前往蒙德的路上，侦察骑士安柏接受了清剿丘丘人营地的委托，并护送两人入城。这个看似普通的插曲，在尾声会得到回响：安柏早发现丘丘人聚落正在不自然地靠近蒙德。龙灾不是唯一正在逼近的威胁，深渊教团对城市的试探已经开始。

蒙德城刚刚展开它明亮、自由的一面，特瓦林便掠过城市上空。数道龙卷撕开街道，旅行者被卷上高空。危急时，一个看不见身影的声音让「千年的流风」托住旅行者，引导其收束风元素、击退巨龙。风之翼原本只是安柏赠予新朋友的入城礼物，此刻却成为旅行者第一次参与守护蒙德的工具。

::: scene 龙灾袭城：陌生的声音，与林间同一种风
> 是我让千年的流风助你，令你不会坠落……
> 现在想象，你能收束这一缕风。让它破开云翳……
> —— 神秘的声音 · 魔神任务「龙灾」

温迪在这里仍没有公开身份。他不以风神姿态接管战斗，而是让旅行者借风完成行动。这与结尾形成很早的呼应：他习惯提供帮助，却不愿把帮助变成支配。对旅行者如此，对特瓦林也如此。
:::

凯亚目睹战斗后，把两人带到西风骑士团总部。代理团长琴正承受双重压力：城内需要救援，至冬使节又借龙灾向骑士团施压。旅行者获得「荣誉骑士」称号，与安柏、凯亚、丽莎分别进入四风守护的废弃庙宇，破坏特瓦林借以汲取力量的结晶。

庙宇探索在玩法上是教学，在剧情上则补出一个被忽略的事实：这些供奉守护者的场所早已荒废，连特瓦林自己的庙宇也不例外。安柏承认，风魔龙曾经是「四风守护」之一；丽莎再向前追溯，才让「袭击城市的怪物」与「曾经保护城市的龙」重新成为同一个生命。

::: insight 第一幕真正建立的，不是讨伐路线，而是两种观看方式
骑士团必须先从城市安全出发，判断风魔龙的威胁；温迪则始终从特瓦林的经历出发，追问它为何变成这样。两种视角都合理：居民承受的破坏是真实的，特瓦林曾受毒血侵蚀也是真实的。序章没有把「讨伐」写成愚蠢，也没有把「拯救」写成轻松的善意。琴之后的挣扎，正来自她同时理解这两边。

旅行者则提供第三种可能。净化泪滴的能力，让「缓解痛苦」不再只是温迪的愿望，而成为可以执行的办法。三幕故事因此不是「大家突然理解巨龙」，而是先找到技术路径，再为这条路承担政治与行动上的代价。
:::

### 第二幕 为了没有眼泪的明天 {act, ver:序章·Ⅱ, p:[16,26], spoiler:mid, sub:诗人的计划 → 私下结盟 → 摘星崖的失败重逢 · P16-P26}

骑士团总部外，旅行者再次遇到那个绿衣少年。这一次，他自称连续三届「最受喜爱吟游诗人」冠军温迪，并用歌谣讲出特瓦林的过去：天空之龙曾受诗人的琴声吸引，学习歌唱；后来在另一条恶龙杜林袭来时守护蒙德，咽下毒血、陷入沉睡。多年以后它重新苏醒，曾经受其保护的人却已不再认识它。

温迪看到旅行者净化赤色结晶，才明确说出那是特瓦林「因为痛苦流出的眼泪」。他原本想凭自己唤回朋友，现在则需要两样帮助：旅行者的净化能力，以及风神曾经弹奏的天空之琴。只要琴声能够越过噩梦，他相信特瓦林仍能记起自己是谁。

::: scene 借琴失败：神明说出真话，却只被当成可笑的诗人
> 我已经不能再隐瞒了！我虔诚的信徒啊，喜悦吧！在你面前的，正是风神巴巴托斯本人——
> 没别的事情的话，我回去继续处理教堂的文件了。
> —— 温迪与修女歌特琳德 · 魔神任务「温迪的计划」

这段喜剧同时解释了蒙德篇的制度困境。天空之琴不是谁声称拯救城市便能取走的道具；正常出借需要团长、主教与民众代表协商签文件。修女还认为，即使风神降临，也不会原谅「背离东风的愚兽」。温迪越是直接表明身份，越显得不可信；他要保护的龙，在正式话语里已经先被定了罪。

于是故事转向一次并不光彩、却目标明确的违法行动。旅行者潜入教堂取琴，被守卫发现后逃进迪卢克的酒馆。迪卢克没有把他们交出去，反而提供庇护，并约来另一位不能在公开场合支持他们的人——琴。
:::

打烊后的酒馆里，迪卢克特意说，他联系的是「琴」，不是作为「团长」的琴。琴相信毒血与深渊腐蚀的解释，却承认「代理团长」绝不能公开表达善意：在愚人众的外交压力下，那会被理解为纵容与不作为。她不是没有判断，而是公开身份限制了她能采取的行动。

迪卢克则一向厌恶骑士团的程序与掣肘，却用自己的情报网追查到，愚人众已经先一步偷走天空之琴。他们借龙灾要求接管城防，也觊觎与风神有关的力量。于是，三个立场并不相同的人暂时结盟：琴提供内部判断，迪卢克提供灰色手段，温迪提供对特瓦林的理解。旅行者把这三条路连接起来，从愚人众藏身处夺回琴，再用收集到的风龙泪滴修复它的力量。

::: insight 这场结盟，让「自由」没有停留在反对规矩
如果只把温迪看作不受约束的诗人，蒙德篇很容易被读成「制度冷漠、自由正确」。但第二幕的人物安排更复杂：温迪需要琴对公共责任的理解，也需要迪卢克在制度之外行动的能力。自由不是谁退出规则便能独自完成拯救，而是人们仍能为自己的判断负责。

琴尤其值得注意。她没有辞去职务，也没有发表一场挑战外交压力的演说；她选择承担私下行动的风险。这个选择不如决战耀眼，却使「不杀死特瓦林」第一次从温迪个人的愿望，变成更多人愿意共同承担的方案。
:::

准备完成后，众人来到摘星崖。温迪拨动修好的天空之琴，特瓦林真的应声而来。它听见旧曲，眼神陷入回忆；温迪也看出它仍在回应那段共同过去。眼看交流即将成立，深渊法师突然现身，反复告诉特瓦林：巴巴托斯早已抛弃它，现在又要欺骗它；它已与蒙德为敌，再也无法回头。

特瓦林转向温迪身边的人，问他们是否一起来猎杀自己。天空之琴在冲突中损坏，刚刚打开的交流窗口再次关闭。温迪的身份却在这一刻暴露——琴与迪卢克终于确认，这个一路插科打诨的诗人就是巴巴托斯。

::: scene 摘星崖：深渊最有效的谎言，是把过去变成无法回头的判决
> 他早就已经抛弃了你……
> 你已经与蒙德为敌，无法回头了。
> —— 深渊法师 · 魔神任务「与巨龙重逢」

深渊法师并没有凭空制造一种全新的情绪，而是利用特瓦林已有的伤口：被遗忘、被误解、与旧友久别。它先承认特瓦林的愤怒，再把愤怒推成唯一合法的身份——既然蒙德厌弃你，你就只能与蒙德为敌。

因此，最终之战要击碎的并不只是生理上的毒血凝块。真正需要打破的，是「一切已经无法挽回」这个结论。摘星崖的失败也说明，琴声和旧情确实有效，却不能只靠一次感动解决长久积累的创伤。
:::

迪卢克拒绝把下一步变成漫无目的的搜捕。他利用情报网找到深渊法师，众人由此转向风龙废墟：既然对话被腐蚀的源头打断，就先清除那个源头。

### 第三幕 巨龙与自由之歌 {act, ver:序章·Ⅲ, p:[27,34], spoiler:mid, sub:风龙废墟决战 → 不被命令的守护 → 教堂外的另一盘棋 · P27-P34}

迪卢克循情报追到深渊法师，众人进入风龙废墟，破除封印、抵达特瓦林所在之处。温迪在决战中明确指出，特瓦林身上发亮的两处，是凝固在旧伤上的毒血；深渊教团正是集中力量诅咒伤口，腐蚀它的精神。此前「拯救」所需的琴声与理解，此时转化为明确行动：破坏凝血，终止持续加深的痛苦。

空中追逐与废墟决战因此具有不同意义。玩家瞄准的不是特瓦林的要害，而是附着在伤口上的紫黑色凝块。温迪一边助战，一边对它道歉，请它再忍耐片刻。战斗的目的不是让败者服从，而是移除它无法自行摆脱的侵蚀。

废墟开始崩塌时，刚刚被击败的特瓦林反而从坠落中托起众人。温迪与它并肩飞过天空，说他们已经很久没有这样一起飞了。特瓦林问出的却不是伤势，也不是蒙德是否原谅自己，而是：为什么这次不像从前一样，要我「守护」？

::: scene 终局：自由不是取消责任，而是重新获得选择
> 我不希望你听从深渊，但这不代表你必须听从我啊，特瓦林。
> 被神明命令的「自由」，也算是一种「不自由」吧。
> 就算没有那个身份，你不也还是守护了我们吗？
> —— 温迪 · 魔神任务「为了青色的身影」

特瓦林的问题说明，它并没有简单厌恶「四风守护」的职责。恰恰相反，即使被城市和神明伤得最深，它仍以这个身份理解自己的价值。温迪若此刻宣布「你自由了，不必再守护」，同样是在替它决定答案。

所以温迪只指出一个已经发生的事实：没有神的命令，特瓦林刚才依然救了他们。守护不再只是眷属对神明的义务，而可以是它自己作出的选择。温迪最后给予祝福，请它「飞得更加从容一些」，不是授予新职位，也不是发布新命令。

这也解释了温迪看似矛盾的做法。他愿意借琴、参与战斗、给予力量，却始终没有以「我是你的神」迫使特瓦林回头。拯救不是把对方恢复成自己期待的样子，而是让它重新拥有理解和选择的能力。
:::

一天以后，琴向市民澄清龙灾真相。城市的反应并没有整齐地变成感动：有人感谢守护者归来，有人仍疑惑应当原谅它到什么程度，也有人只关心商路与酒馆终于恢复。尾声保留这些声音，使特瓦林的获救不等于所有社会关系瞬间复原。理解需要时间，温迪所说的「风向是会转变的」，更接近一种耐心的期待。

凯亚则揭示了另一层危机。他故意留在防御空虚的城内，观察并套取深渊潜入者的情报：丘丘人的总攻与腐化特瓦林的计划背后，有一位被称为「公主殿下」或「王子殿下」的统领者。旅行者寻找的血亲，由此与深渊教团第一次发生明确联系。

庆功餐后，众人去教堂归还已经损坏的天空之琴。温迪用幻术暂时把它「修好」，趁芭芭拉发现前匆匆离开。但教堂外，愚人众执行官「女士」突然袭击，夺走温迪的神之心并击晕旅行者。她嘲笑放弃统御蒙德的神只剩这点力量；温迪则反问她，是否只是凭从主人那里借来的力量才有嘲笑的资本。

::: scene 教堂外：另一套关于力量与统御的答案
> 放弃统御蒙德的神，就只剩这点力量……
> 哦？你嘲笑我的资本，就是从主人那里借来的力量吗？
> ——「女士」与温迪 · 魔神任务「尾声的尾声」

这场袭击把温迪刚刚坚持的价值推到反面。女士以能否压制他人衡量神的力量，并以夺取神之心完成任务；温迪则刚放弃用神的身份命令特瓦林。两种逻辑在同一场戏里碰撞，但序章没有立刻给女士完整背景，也没有把神之心的争夺解释清楚。

随后，温迪在风起地说明，神之心是与天空岛共鸣的魔力器官，也是七神之座的象征；冰之女皇正在谋夺其他神灵的神之心。五百年前的大灾之后，她已经与温迪断绝交流。蒙德本地危机结束了，七神与愚人众的棋局却刚刚露出边缘。
:::

温迪没有让旅行者立刻追查女士，而是建议前往邻国璃月，赶上岩神一年一度的请仙典仪。临别时，他提醒旅行者记住旅途本身的意义：飞鸟、诗歌、城邦，女皇、愚人和怪物，都是旅途的一部分；终点并不意味着一切。

这句话也重新安排了序章两条主线的分量。旅行者没有找到血亲，却已经通过特瓦林理解了一种重逢：重逢不是把关系恢复到从未受伤的样子，而是在伤害发生之后，仍允许彼此重新选择。

## 人物的变化 {id:cast, spoiler:mid}

::: arc 温迪：从想替朋友解除痛苦，到不替朋友定义自由
起点|他在低语森林尝试清除诅咒，希望凭旧情与天空之琴唤回特瓦林的本性。
压力|摘星崖的交流被深渊打断，证明旧曲能唤起记忆，却不能自动消除被抛弃、被遗忘的创伤。
选择|他参与决战、清除毒血，却始终不以风神身份命令特瓦林服从。
终点|他承认特瓦林仍珍视守护职责，也不把自己理解的自由强加给它；祝福代替命令，成为这段关系的新起点。
:::

::: arc 特瓦林：从只能以受害者身份理解自己，到重新作出守护的选择
起点|毒血与深渊腐蚀加深痛苦，苏醒后的它又被视为「风魔龙」，与蒙德和旧友的关系都陷入断裂。
压力|深渊法师把它的愤怒解释成无法回头的证据；温迪等人则坚持腐蚀可以被清除，关系仍有可能修复。
选择|废墟崩塌时，它主动托起众人。这一行动发生在任何新命令之前。
终点|它不必先被重新任命为「四风守护」，才配守护蒙德。身份没有替它作答，行动由它自己完成。
:::

::: arc 琴与迪卢克：两种公共责任，在正式制度内外会合
琴|她理解特瓦林可能身不由己，却不能以代理团长身份公开表达善意。私下结盟让她把个人判断转化为实际帮助，同时继续承担城防与外交责任。
迪卢克|他不喜欢骑士团的程序，却并非拒绝守护城市。他提供庇护、情报与追踪能力，使温迪的方案从歌谣变成可执行的救援。
共同点|两人都没有等待一个全知全能的神替蒙德解决问题。温迪能唤回旧友，但城市能够选择不杀死特瓦林，仍需要人的行动。
:::

## 终局之后：三条没有结束的线 {id:truth, spoiler:heavy}

::: insight 特瓦林与血亲：两种「被深渊带走的人」
深渊法师向特瓦林宣称，它已经与蒙德为敌、无法回头；血亲则成为深渊教团的统领者。序章没有把两者简单等同，但并置已经足够醒目：旅行者能否像温迪面对特瓦林那样，在理解与立场之间找回自己的亲人？

后续故事会不断加深这个难题。蒙德篇提供的不是保证团圆的答案，而是一个原则：不要把对方此刻站的位置，当成对方永远无法改变的全部。
:::

::: insight 神之心与神之力：棋子的价值，不等于神的全部
女士夺走神之心后，立即把它与自己珍藏的棋具相比。此后七国的神之心争夺也逐渐带有棋局意象。但在蒙德篇里，温迪与特瓦林的关系并不由这枚器官证明：他失去神之心，仍然是可以给予祝福的巴巴托斯。

这里不宜进一步推断温迪是否故意放水，或整场夺心是否另有安排——序章没有给出足够证据。能够确认的是，女士以力量判断神，温迪以放弃统御实践自己的神性，两种价值由此形成对照。
:::

::: insight 「自由」不是不需要他人，而是关系不再只靠命令维系
温迪并没有让特瓦林离开蒙德、切断所有责任；他也没有要求自己完全不介入朋友的选择。相反，他回来、道歉、助战、祝福，承担了关系中的责任。被拒绝的是支配，不是关心。

这使序章标题中的「自由」比「想做什么就做什么」更具体：我可以守护你，因为这是我理解之后仍愿意做的事；我也可以帮助你，而不把你的未来变成我的意志。
:::
